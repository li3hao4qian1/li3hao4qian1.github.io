# Chess2B2T · 国际象棋工具箱

一个纯静态、可离线使用的国际象棋工具站：在棋盘上走子，导入 / 导出 PGN，查看棋谱与注释，读写 FEN。内置标准 8×8 与 Half Chess 4×8 两种模式。

## 功能

- **棋盘**：点击或拖拽走子，合法着法提示、升变选择、将军高亮、上一步标记
- **复盘**：着法列表逐步跳转、自动播放、翻转棋盘、键盘导航
- **变种**：一键切换标准 8×8 / Half Chess 4×8；12 种合法初始底线可选，支持随机、按布局开局、任意 4×8 FEN 载入
- **PGN 导入**：粘贴或拖入 `.pgn` 文件；支持多局文件、`{注释}`、`0-0` 写法、`SetUp` + `FEN` 起始局面，按 FEN 宽度自动识别模式
- **PGN 导出**：实时预览、复制、下载 `.pgn`、生成可分享的链接；Half 对局自动写入 `Variant` 与 `SetUp` / `FEN`
- **FEN**：显示当前局面，载入任意 FEN 并从该局面继续走子，解析易位权 / 过路兵 / 回合信息
- 浅色 / 深色主题，桌面与手机自适应

## Half Chess（4×8）

棋盘为 a–d 四列、1–8 八行，白方视角左下角 a1 为深格、右下角 d1 为白格。每方一车、一象、一马、一王，没有后；白兵在第 2 行、黑兵在第 7 行。

**初始底线**：底线四枚棋子的摆放不唯一，但王必须在 b 或 c 列，黑方按同列镜像。工具内置 12 种合法布局（王在 c 的 6 种、王在 b 的 6 种），默认 `rbkn / RBKN`。在「变种」面板选中布局后点「按此局面开局」即可；也可以随机布局，或直接载入任意 4×8 FEN。切换模式或换布局会开始新对局，当前有棋谱时会先弹窗确认。

**走法**：与国际象棋基本一致——兵可双步、斜吃、吃过路兵，到达第 8 / 1 行升变。升变只能选择初始局面中除王、兵以外存在的棋子，因此默认布局下只能升为车、象、马，没有后。

**易位**：王到 a 列记 `O-O-O`、到 d 列记 `O-O`，同时车移到 b 或 c 列；王车未动、中间无子、王不在被将、路径与目标格不受攻击等前提同国际象棋。只有车在 a 或 d 边列时该侧才有易位权，布局面板会按车的位置自动给出 `Q` / `K` / 无。

**记录**：Half 对局的初始局面写入 PGN 的 `SetUp` + `FEN` 标签，并标记 `[Variant "Half Chess"]`；导入时看到 4 列 FEN 或该标签会自动切到 4×8 模式，标准对局则自动回到 8×8。

## 使用

直接双击 `index.html` 即可使用（全部资源均为相对路径，无需服务器）。

也可以用任意静态服务器预览：

```bash
npx serve .
```

部署到 GitHub Pages 时，把本目录内容放到仓库根目录（或 `docs/`）并开启 Pages 即可。

## 目录

```
chess2b2t/
├─ index.html          页面结构
├─ css/style.css       主题与布局（深色默认，data-theme="light" 为浅色）
├─ js/app.js           棋盘渲染、走子交互、导航、导入导出
├─ js/pgn.js           PGN / FEN 解析与生成
├─ js/halfchess.js     Half Chess 4×8 规则引擎（与 chess.js 同形接口）
├─ vendor/chess.js     棋规引擎（chess.js 0.10.3，MIT）
├─ vendor/LICENSE      chess.js 许可证
└─ img/                12 枚棋子图（wp/wn/wb/wr/wq/wk、bp/…/bk）
```

棋子图按 `{颜色}{兵种}.png` 命名：`w` 白方、`b` 黑方，`p` 兵、`n` 马、`b` 象、`r` 车、`q` 后、`k` 王。替换 `img/` 中的图片即可换肤，无需改代码。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `←` / `→` | 上一步 / 下一步 |
| `Home` / `End` | 开局 / 末步 |
| `空格` | 自动播放或暂停 |
| `F` | 翻转棋盘 |
| `Esc` | 取消选中或关闭升变面板 |

在输入框中输入时不会触发上述快捷键。

## PGN 解析说明

- 着法按标准 SAN 校验，非法着法会给出「第 N 着无法识别」并保留此前已解析的着法
- `{...}` 注释会保留并随导出写回；行注释 `;` 会被忽略
- 变例 `(...)` 不展开，仅提示「已忽略 N 个变例分支」
- 结果标记 `1-0`、`0-1`、`1/2-1/2`、`*` 会同步到对局信息
- Half 对局按 4 列 FEN 或 `[Variant "Half Chess"]` 自动识别；导出时自动补 `SetUp` / `FEN`。手写 4×8 FEN 时空行要写 `4`（如 `rbkn/pppp/4/4/4/4/PPPP/RBKN w Qq - 0 1`），写成 `8` 会提示行宽不符

所有计算都在浏览器本地完成，不会上传任何棋谱。
